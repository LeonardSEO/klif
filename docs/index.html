Never lose a sideloaded app to the 7-day limit.

Klif is a free desktop app for Mac, Windows and Linux. It installs SideStore and IPA files on your iPhone, shows when each app expires, and puts reminders in your calendar before that happens.

Download Klif Free and open source

How it works

Set it up once, then let your calendar do the remembering.

  1. Connect your iPhone

    Plug it into your computer with a cable and open Klif. After the first time, Wi-Fi works too.

  2. See what expires when

    Open Expiry Overview. Klif reads the expiry date of every sideloaded app straight from your device, without signing in.

  3. Add reminders to your calendar

    Click Add reminders to calendar and open the file. Your phone, laptop and watch will remind you to refresh.

Klif for macOS

macOS 11 or later. Works on Apple silicon and Intel. Nothing else to install.

Install

  1. Open the downloaded .dmg and drag Klif to Applications.
  2. Open Klif. macOS will say it can't check the app, because Klif isn't notarized by Apple yet.
  3. Go to System Settings, then Privacy & Security, and click Open Anyway next to Klif.
  4. If macOS says the app is damaged, run this in Terminal and open it again:
    xattr -dr com.apple.quarantine /Applications/Klif.app

Klif for Windows

Windows 10 or 11. Klif needs iTunes installed to talk to your iPhone.

Install

  1. Install iTunes if you don't have it.
  2. Run the downloaded installer.
  3. If Windows shows "Windows protected your PC", click More info, then Run anyway. Klif isn't code-signed yet.
  4. Open Klif from the Start menu and plug in your iPhone.

Klif for Linux

x86_64 and ARM64. Klif needs usbmuxd, which most distributions already include.

Install

  1. Make sure usbmuxd is installed, for example sudo apt install usbmuxd or sudo dnf install usbmuxd.
  2. Install the .deb or .rpm with your package manager, or use the AppImage: chmod +x Klif*.AppImage and run it.
  3. On NixOS, run nix run github:LeonardSEO/klif.

Good to know

What Klif does and doesn't do, so there are no surprises.

The 7 days stay 7 days

Apple sets that limit for free accounts and nothing removes it. Klif makes sure you know in time. Refresh in SideStore, or reinstall with Klif.

Export again after a refresh

Each refresh gives the app a new expiry date. Add the reminders again afterwards so your calendar stays correct.

Your Apple ID stays on your computer

Klif only signs in to Apple to install apps, and stores your login in your system keychain. Reading expiry dates needs no sign-in, and nothing is sent to us.

Early software

Klif is new and builds aren't signed yet. Found a problem? Report it on GitHub.
